# MATH 3260 Stage 2 — Chapter 1 Preview

This package is designed to be added to the existing `mathxiao/Math3260Homework` repository without replacing the current Stage 1 homepage.

## Included
- 3 Chapter 1 sessions
- 6 problems per session
- difficulty mix: 2 Easy, 3 Medium, 1 Slightly challenging
- full worked solutions after checking
- similar practice after incorrect answers
- local MathJax path compatible with the existing repository

## Upload these files
- `stage2.html`
- `assets/stage2_ch1.js`
- `assets/stage2_app.js`
- `assets/stage2.css`

The preview will use the MathJax bundle already present in the main repository.

Then open:
`https://mathxiao.github.io/Math3260Homework/stage2.html`

The existing `index.html` remains unchanged.
